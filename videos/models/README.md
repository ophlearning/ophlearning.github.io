# 教學影片的解剖模型庫

這個資料夾放教學影片共用的解剖模型。每個模型是一份以 mm 為單位的解剖資料，加上幾個「鏡頭」（視角）；影片裡看到的每一格畫面，都是某個模型在某個狀態下、從某個鏡頭畫出來的。這樣做的原因是：同一份解剖可以換鏡頭看，放大、切面、正面永遠互相一致，不會各畫各的。

網站頁面不會直接連到這裡；各支影片的原始檔（`videos/src/<影片>/`）會載入這裡的模型。

## 設計原則（2026-11-04 與站長討論後定案）

1. **以 mm 建模，比例照教科書，數值附出處。** 文獻沒有給數值的地方，在下面的數值表標「示意」，出處還沒核對的標「[待核對出處]」。原因是舊的眼瞼圖把眼球畫成實際的兩倍大，看的人會把錯的比例記進腦子裡。
2. **預設亞洲人解剖。** 觀眾以台灣的住院醫師為主，他們開刀遇到的是亞洲人的眼睛。眼瞼預設亞洲人單眼皮，白人版本保留下來做對照。
3. **標籤一律「中文 English」並列。** 中文用台灣常用譯名，英文用解剖或手術名稱，讓看的人同時記住兩種說法。
4. **手術步驟同時顯示兩個同步視角。** 例如眼瞼手術同時有矢狀切面和正面。第二個視角的尺寸由第一個換算，不另外畫，所以同一個結構在兩圖的高度一定一樣。
5. **正面和俯視視角用「開窗」表示切口與分層。** 每個窗有一個深度，窗內比這個深度淺的組織全部拿掉。手術一步步往深處走，只是把窗的深度往下調。
6. **新模型先交一張樣本圖給站長確認，再做整支影片。**
7. **每個模型附自我檢查（`check.js`），改模型或出片前都要跑過。** 檢查的是解剖關係（例如融合點在瞼板上緣的上方還是下方），以及兩個視角的尺寸有沒有對上。

## 模型清單與進度

前段、後段、眼外肌三個模型共用同一顆眼球：眼球只建一次，換不同的鏡頭和放大倍率來看。

| 模型 | 手術中同步的兩個視角 | 涵蓋的手術 | 進度 |
|---|---|---|---|
| 眼瞼（上、下瞼） | 矢狀切面＋正面 | entropion／ectropion、ptosis、雙眼皮、lateral tarsal strip、眼瞼腫瘤重建、PLTR | 上眼瞼解剖樣本已確認；PLTR 的手術狀態與翻瞼視角已做（其他術式未做）；下眼瞼未做 |
| 眼眶與淚道 | 冠狀或軸向切面＋正面 | 眶骨骨折、眼眶減壓、DCR、眼球摘除 | 未開始 |
| 前段 | 前段矢狀切面＋手術顯微鏡俯視 | 白內障、PK／DALK／DSAEK／DMEK、翼狀胬肉、trabeculectomy、tube、MIGS | 未開始 |
| 前段放大 | 角膜分層；隅角＋前房角鏡視角 | 屈光雷射、CXL、SLT、LPI | 未開始 |
| 後段 | 眼球矢狀切面（三孔 PPV）＋廣角眼底 | RD（PPV、scleral buckle、pneumatic）、IVI、PRP | 未開始 |
| 黃斑放大 | OCT 式分層＋黃斑俯視 | ERM／ILM peel、macular hole＋氣體 | 未開始 |
| 眼外肌 | 眼球軸向俯視＋術者視角 | recession／resection、斜肌手術 | 未開始 |

建議的製作順序：先用眼瞼模型重做 PLTR 影片，把「雙視角＋手術動畫＋出片上傳」整條流程跑通一次；再做眼球（前段），因為角膜、白內障、青光眼的影片都會用到。

## 眼瞼模型（`eyelid/`）

### 檔案
- `lid.js`：矢狀切面（右眼、經瞳孔中央）。畫出眶上緣與 roof、眶隔、腱膜前脂肪、levator 與 aponeurosis、Müller、瞼板與 meibomian gland、上穹窿、superior rectus、眼輪匝肌、睫毛與毛囊、gray line、MCJ、marginal 與 peripheral arcade、眼球（角膜、虹膜、水晶體、睫狀體）。
- `coronal.js`：正面（檢查者面對病人，右眼：左＝temporal、右＝nasal），可以開窗逐層打開。
- `sample.html`、`sample-asian.jpg`：樣本頁與輸出的樣本圖（兩圖同步、亞洲人單眼皮）。
- `check.js`：自我檢查。

### 座標怎麼定
矢狀切面以眼球中心為原點，單位 mm，左＝前、上＝上。眼瞼裡的每個組織用「沿著眼球表面、距瞼緣幾 mm（s）」和「離眼瞼後表面多深（u）」來定位。這樣一來，瞼緣內轉、瞼板切開後轉出來，所有組織都在同一套座標上一起變形；「切口離瞼緣 3 mm」也直接就是 s＝3。

正面圖以角膜反光點為原點。上眼瞼每個結構在中央那條線上的高度，是把矢狀切面的位置投影到正面得來的；往內外眥兩側再依形狀變窄。瞼板繞著眼球彎，所以正面看起來比 10 mm 矮，這是投影造成的，不是畫錯。

### 兩種變體
- `asian`（預設）：亞洲人單眼皮。眶隔在瞼板上緣**下方**與腱膜融合，腱膜前脂肪往下延伸到瞼板前方；另有瞼板前脂肪和較厚的皮下脂肪；腱膜往皮膚的纖維止點比較靠近瞼緣，所以沒有 crease。
- `caucasian`：融合點在瞼板上緣上方，有 crease 和皮膚皺褶。

### 手術狀態（目前做到 PLTR）
畫圖時傳入 `state`，數值 0 到 1 表示動作進行到哪裡：
- 矢狀切面：`curl` 疤痕性內翻（瞼緣以後瞼緣角為軸往內滾，瞼板往前弓起，睫毛被擋在角膜上）、`cut` 從結膜面離瞼緣 3 mm 切穿瞼板、`plane` 前層和瞼緣側瞼板之間的分離平面、`k` 瞼緣側瞼板轉出、`over` 額外往外轉的角度、`tuck` 上方瞼板的切緣被拉下塞到瞼緣側瞼板前方、`suture` 縫線、`scar` 結膜疤痕。
- 正面（皮膚面）：`evert` 瞼緣內轉到外翻（內轉時睫毛蓋到角膜上，外翻時露出一條後瞼緣）、`incision` 切口（在結膜面，所以畫虛線）、`marks` 縫線標記、`spacing` 間距、`sutures` 三組縫線、`tight` 綁緊程度。
- 翻瞼（`CORONAL.drawEverted`，術者看到的樣子）：上眼瞼翻開，瞼板結膜面朝向觀眾，瞼緣和睫毛在上、翻摺處在下；瞼板高度和切口離瞼緣的距離由矢狀切面換算。`scar` 疤痕程度、`incision` 切口（由外側往內側畫）、`incWavy` 切口不直、`incShort` 切口太短、`ends` 兩端、`lenArrow` 長度、`bleed` 出血、`notch` 瞼緣缺口、`nasalShort` 鼻側瞼板較短。
- 腱膜止點從瞼緣上方 3.3 mm 開始，避開 PLTR 的切口。
- 內翻角度、轉出角度、塞入距離都是示意值。自我檢查只驗證幾件事的方向對不對：內翻時睫毛碰到角膜、矯正後睫毛離開角膜、上方瞼板切緣在瞼緣側瞼板前方、兩圖的切口高度一致。

## 怎麼看樣本、怎麼跑檢查

在 `videos/models/` 這一層執行：

1. 下載字型（只要做一次，不進 git）：`mkdir -p fonts && cd fonts && npm pack @fontsource/noto-sans-tc@5.1.1 && tar xzf fontsource-noto-sans-tc-5.1.1.tgz && cd ..`
2. 自我檢查：`cd eyelid && node check.js && cd ..`
3. 輸出樣本圖：`node shot.js eyelid/sample.html eyelid/sample-asian.jpg 2`
