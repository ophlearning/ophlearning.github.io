# 白內障 ④：PCR 案例錄影判讀（footage notes）

2026-11-10 Claude 判讀。錄影是 `videos/src/cataract-series/footage/case-pcr.mp4`（不進 git；以下簡稱「案例 B」）。檔名、雲端檔案 ID、連結與病人資料都不寫進 repo。聲音全部不用（抽格一律 `ffmpeg -an`）。

- 規格：50:14（3014.4 s），1280×720，30 fps，H.264，Clipchamp 輸出；90,433 格。
- 判讀方法：全片每個關鍵格（約每 5 秒）做縮圖表；關鍵段落每 1–2 秒裁切眼睛放大；必要的時刻抽全解析度影格、加格線讀座標；全片逐格算相鄰格亮度差找剪接點；60 張全解析度影格算平均與標準差找燒進畫面的文字。
- 信心：**高**＝畫面上直接看得到；**中**＝看得到動作，用途是推論；**低**＝看不清楚，只是可能。red reflex 很弱，囊袋與玻璃體的細節大多看不清楚，所以「低」的項目不少，都列在最後的「待確認」。

## 1. 去識別：燒進畫面的文字
- **整部錄影沒有燒進畫面的文字、標誌或參數欄**（和案例 A 不同）。
  - 60 張平均於 0:01–50:11 的全解析度影格：平均圖、標準差圖、分三段（0–14:05、14:15–38:32、38:42–結尾）的高通平均圖都看不到任何靜止的字形或框。
  - 片頭 0:00–0:03（每 0.5 秒）與片尾最後 12 秒（每 1 秒）逐張看過：一開始就是手術畫面，最後是閉眼的眼瞼；沒有片頭卡、片尾卡或日期。
- 只有兩條編碼邊線（不是文字，但裁切要避開，可以當 overlay 登記）：
  - 最上面一列 y = 0 偏亮（平均 130，下面第 2 列 106；每一張都亮 11–33），y = 1 也稍亮（110）→ 登記 `{ x: 0, y: 0, w: 1280, h: 2 }`。
  - 最右一欄 x = 1279 偏暗（平均 17，旁邊 67；每一張都暗）→ 登記 `{ x: 1279, y: 0, w: 1, h: 720 }`。
  - 左側 x < 約 150 是鏡頭暗角（亮度漸變，不是邊線），不用登記。
- 畫面上可識別的只有病人眼周皮膚與眼瞼（包了手術單）；裁切只留眼睛與角膜周圍即可。

## 2. 眼別、方位與「約 14:00 畫面方向改變」
### 2.1 14:00 附近不是轉向，是顯微鏡平移
- 系列規格書記的「約 14:00 起畫面方向改變」（低解析度縮圖判讀）實測是 **14:08.2–14:08.8 顯微鏡的 XY 平移**：眼睛從畫面上半部移到中央，上方那片開瞼器葉片因此入鏡、下方葉片只剩上緣。
  - 逐格亮度差在這 0.6 秒內每格 4–12（全片中位數 0.9），是連續移動，不是剪接（硬剪接是單一格跳 50 以上）。
  - 平移前後：左側的睫毛、角膜下緣的同一顆水珠、主切口（畫面右下）與 side port（畫面左）的位置都一樣 → **同一眼、同一台刀、方向沒有轉**。
- 38:49–38:50（手擋鏡頭後）與 41:25.7 也各有一次取景改變（眼睛回到畫面上半部、下方葉片變大）。41:25.7 是**單一格跳 62**（前後格差 ≤ 4），前一秒是左側的針筒、下一秒是經主切口的 J 形 cannula，**可能是剪接點**（可能有一小段被剪掉，待確認）。方向一樣。
- 其他亮度差高峰都是手或棉棒擋住鏡頭、或角膜表面沖水的反光（8:09–8:11、14:22.6、21:21–21:25、22:51–22:54、36:02、42:06 等），不是剪接。

### 2.2 術者位置與眼別
- **術者坐 superior（12 點）：畫面下＝12 點**（信心：高）。
  - 主切口在畫面下方偏右（keratome 0:25–0:33、撕囊鉗、phaco、I/A、IOL injector 都從這裡進）；side port 在畫面左側。
  - 片尾閉眼（50:12–50:14）：濃密、較長的睫毛在下方那片眼瞼 → 下方是上眼瞼。
- **眼別判讀：左眼 OS**（信心：中，**要站長確認**）。
  - 畫面右側眼角是粉紅色肉質組織、沒有睫毛（像 caruncle／plica，0:01.5、0:12 放大看）；左側眼角有睫毛 → 右＝medial（nasal）、左＝lateral（temporal）。
  - 開瞼器的臂與鉸鏈往畫面左邊延伸（0:12、48:23、50:10），一般放在 temporal 側。
  - 術者坐 12 點時，畫面右＝病人的右側；左眼的病人右側是 nasal → 和上面兩點一致，所以是 OS。

## 4. PCR 什麼時候出現、看得到什麼
**這段錄影 red reflex 很弱，教科書的 PCR 線索大多看不到。** 以下是 Claude 能看到的，信心都不高，要用 OP note 或站長確認。

### 4.1 最可能：12:50–12:58，第一段乳化的末段（核還沒處理完）
- 看得到的：
  1. 12:54–13:01 瞳孔下半（畫面左下）出現之前沒有的橘紅色反光；上方是一大塊核的直邊。
  2. 12:57–12:58 還剩一大塊核，phaco tip 與 chopper 就一起退出（2026-11-10 出片前每 0.1 s 再讀：chopper 先退，12:57.1–12:57.3；phaco 12:57.4–12:58.4）。
  3. 退出後約 5 秒（13:03）才經 side port 打 OVD；13:29–14:02 用 cannula 經主切口把大核塊托到前面、瞳孔中央。
  4. 剩下的核在 14:38–17:03.8 用 phaco 乳化，左手換成**直的細器械**放在核塊旁邊／下方（12:58 以前的左手器械是彎的 chopper）。
  5. 之後的處置都是 PCR 才會做的：新的／擴大的 paracentesis（23:05）、雙手前段玻璃體切除（24:00 起三次）、白色顆粒染色（44:48）、縫合所有切口（46:35 起）。
- 看不到的（不能在旁白當成本例的線索）：前房突然變深、瞳孔突然放大、核塊往後沉或歪掉、玻璃體出現在切口或被吸到 tip、清楚的後囊破口邊緣。
- 第一個動作（觀察到的順序）：**先退出器械，再補 OVD**。教科書常說的是「tip 留在眼內、停超音波、先經 side port 打 dispersive OVD 再退」（待文獻確認，見 spec 的待查證）。本例若真的是 12:5x 發現 PCR，這個順序可以拿來對照；但不能確定術者那一刻已經知道破了，**旁白不評斷本例術者**，只講建議的順序並標出處。

### 4.2 另一個可能：皮質處理時（19:18–20:46）
- 20:36–20:43 cannula 碰到撕囊範圍內的後方膜，出現放射狀皺褶與一片偏紅的摺痕，可能是後囊的破口邊緣或被推皺的後囊。
- 22:04 起才出現疑似玻璃體處理的器械；如果 PCR 是在這裡才發生或才被發現，4.1 的步驟就只是處理硬核塊的方法。

### 4.3 處理流程（看得到的部分）
停乳化、退器械 → OVD（side port）→ OVD 把剩下的核托到前面 → 在器械支撐下乳化剩下的核（14:38–17:03.8）→ coaxial I/A 吸皮質（19:18–20:12）→ 做左側切口（23:05）→ **雙手、經角膜緣的前段玻璃體切除**（24:00–27:15、33:30–35:15、38:55–40:10；灌流經左側切口、切割經主切口）→ OVD → **折疊 IOL 經 injector 從主切口植入**（42:51）→ 定位 → **白色顆粒（像 triamcinolone）檢查前房玻璃體並清除**（44:48–45:45）→ **縫合主切口與左側切口**（46:35–50:00）。
- 沒看到的：pars plana 穿刺口、PFCL、核碎片掉進玻璃體腔（瞳孔太暗，看不到也不能排除）。
