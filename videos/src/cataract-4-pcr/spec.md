# 白內障 ④：Posterior capsule rupture（PCR）——怎麼認、當下第一步、之後怎麼處理（規格書草稿）

2026-11-10 訂（草稿）。系列共同的決定（目標、四件事的教學結構、去識別、驗收）見 `videos/src/cataract-series/spec.md`；做法照 ①（`videos/src/cataract-1-wound-ccc/`）：左＝去識別錄影，右＝同一組事件時間同步的 mm 模型切面。錄影逐段判讀、時間碼、裁切與待確認見同資料夾 `footage-notes.md`。

## 目標與觀眾
- 觀眾：已經會做 routine phaco（①–③）、開始自己做核與皮質的住院醫師。
- 看完要能做到（每一項都是「上刀時的動作或判斷會不一樣」）：
  1. **早認出 PCR**：說出並在畫面上指出線索。前房突然變深、瞳孔瞬間放大、核塊不跟 tip 走或往後沉／歪、red reflex 出現有邊緣的清亮區、玻璃體被吸到 tip 或跑到切口。每個線索要有文獻出處，並知道 red reflex 弱時（像本例）哪些看不到。
  2. **當下第一步**：停超音波與吸力、tip 先不要退、經 side port 打 dispersive OVD 封住破口再退；不要讓前房塌（降瓶高、不突然放開腳踏）。說得出每一步的理由（前後房壓力差會把玻璃體往前推）。
  3. **剩下的核怎麼辦**：核塊還在前面，用 OVD 托到前房、在支撐下以低參數乳化；核塊掉進玻璃體腔就不追，留給 VR。
  4. **皮質與玻璃體**：dry aspiration 或低流量；前段玻璃體切除要灌流與切割分開（雙手）、高切速低吸力；經角膜緣或 pars plana 的取捨；用 triamcinolone 看見玻璃體。
  5. **IOL 放哪裡**：依囊袋支撐選 in the bag、sulcus（3-piece、度數調整）、optic capture 或改期／其他固定；single-piece acrylic 不放 sulcus。
  6. **收尾與何時轉診**：切口確認沒有玻璃體、必要時縫合；術後要追 IOP、CME、RD、眼內炎；有核碎片留在玻璃體腔要儘快轉 VR。
- 時間目標 10–12 分鐘；第 2–3 章（認出＋第一步）至少占 40%（系列規格書：④ 的時間重心是「認出 PCR 的線索與第一個動作」）。

## 病例情境
- **站長 2026-11-10 確認（原文照錄）**：
  1. 「這台是不是 OS？」→「對」
  2. 「PCR 發生在哪一步？」→「不太確定，猜測是sculpt或是quadrant時」
  3. 「IOL 是哪一種、放在哪裡？」→「AAB00 put in sulcus」
  4. 「44:48 的白色懸浮物是什麼？」→「我猜是TA要染vitreous」
- 整理後的病例摘要（以站長確認為準，錄影判讀補細節）：OS，術者坐 superior：主切口約 11 點＋side port 約 2 點；phaco 中發生 PCR（站長不確定時機，猜在 sculpt 或 quadrant 移除；錄影判讀最可能在 phaco 末段約 12:50–12:58，兩者相符）→ OVD 把剩下的核托到前房、在器械支撐下乳化 → coaxial I/A → 雙手、經角膜緣前段玻璃體切除 → AAB00 經 injector 植入 **sulcus** → 白色懸浮物（站長猜是 triamcinolone［TA］，用來染出玻璃體）→ 縫合切口。
- AAB00＝Sensar One（one-piece 疏水性壓克力、6 mm optic、C-loop haptic；Wakili 2026，doi:10.1007/s00417-026-07340-y；Danzinger 2025，doi:10.3928/1081597X-20250307-01）。**本例把 one-piece 放在 sulcus**：旁白只描述本例做法，同時照文獻講 single-piece acrylic 放 sulcus 的風險與建議做法（Chang 2009），不評斷術者。
- 旁白的措辭：PCR 時機說「錄影上看不出確切時間，術者推測在刻槽或移除核塊時」；白色懸浮物說「看起來是 triamcinolone（術者推測）」，不說成確定。
- 和系列的 routine 病例（案例 A，OD）不同：錄影面板的方位要寫「左眼 OS」「右＝nasal」；模型的術者視角左右鏡像。
- 沒有手術日期（純學習用）：不做術前速讀包。
- 錄影的限制，旁白要照實說：本例 red reflex 很弱，PCR 的經典線索在錄影上大多看不到 → **線索用模型動畫示範（標「動畫示意」）**，錄影用來看「真實畫面上能看到多少」與處理流程；本例術者的做法只描述、不評斷，建議做法一律標文獻。
