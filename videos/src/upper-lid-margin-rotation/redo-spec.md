# PLTR 影片重做規格：換成新的眼瞼模型

2026-11-04 訂。站長判定舊版的眼瞼圖不及格（只畫瞼緣附近四層、眼球畫成實際的兩倍大、meibomian gland 畫成點），決定用 `videos/models/eyelid/` 的新模型重做這支影片。這份規格寫清楚哪些要改、哪些不動，以及做到什麼程度才算完成；文末的驗收項目在收尾時逐條對照回報。

## 不動的部分
- 旁白、畫面字幕、重點框、右下角來源、章節名稱、參考文獻：`anim/segments.js` 裡這些文字一個字都不改。原因是這些內容已經用 PubMed 查證過，這次只換畫面。
- 語音的念法設定（`tts/tts.py` 的數字轉念法與英文發音表）不改。

## 要改的部分

### 1. 畫面模型
- `anim/engine.js` 裡舊的矢狀切面與正面模型，換成載入 `videos/models/eyelid/` 的 `lid.js`、`coronal.js`，解剖用預設的亞洲人單眼皮。
- 標籤一律「中文 English」並列，例如「瞼板 tarsus」「眶隔 orbital septum」。

### 2. 每一段用哪兩個視角
| 段落 | 左 | 右 |
|---|---|---|
| 片頭 | 標題 | 正面 |
| 1-1 三種機轉、1-2 檢查 | 矢狀（1-2 推近到瞼緣看 MCJ） | 正面；1-2 中段換成翻瞼 |
| 1-3 病因 | 矢狀（疤痕收縮、瞼緣內轉） | 資訊卡（不變） |
| 1-4、1-5、第 2 章、第 7 章、第 8 章 | 全寬資訊卡（不變） | — |
| 3-1 標記、3-2 麻醉 | 正面（皮膚面） | 資訊卡（不變） |
| 4-1 切開、4-2 分離、4-3 放縫線、4-4 綁線 | 矢狀（切口與轉出時推近到瞼緣） | 4-1、4-2 翻瞼；4-3、4-4 正面 |
| 5 術中狀況 | 翻瞼 | 資訊卡（不變） |
| 6-1 BLTR、6-2 從皺褶位置進去 | 矢狀 | 正面（改成雙視角，原本只有矢狀） |

### 3. 模型要新增的狀態（動畫用）
- **矢狀切面**：
  - 疤痕性內翻：後層縮短，瞼緣往眼球轉；posterior lid margin 變圓；MCJ 前移；結膜疤痕與收縮箭頭。
  - misdirected 與 metaplastic lashes。
  - PLTR 切口：從結膜面、離瞼緣 3 mm，切穿結膜和瞼板，可以逐步畫出來。
  - 前層和瞼緣側瞼板之間的分離平面。
  - 瞼緣側瞼板轉出、上方瞼板下緣塞進去。
  - everting suture 的路徑。
  - BLTR 的全層切口，以及從皺褶位置進去時掀起的皮瓣。
- **正面（皮膚面）**：三組縫線的標記與間距、麻醉範圍、縫線出針與綁緊、術後輪廓。
- **翻瞼（新視角）**：
  - 上眼瞼翻開，瞼板結膜面朝向觀眾。瞼板高度、切口離瞼緣 3 mm 都由矢狀切面換算，和左圖一致。
  - 疤痕從細線到整片的程度。
  - 切口逐步畫出、兩端用剪刀補完、長度箭頭、出血、notch、鼻側瞼板較短。

### 4. 版面
- 兩個視角的畫面放大：每個面板從 608×392 放大到至少 600×440。做法是把重點框從 118 縮到約 78 像素高，字級從 19.5 改成 17，最多兩行。
- 頁首、章節進度條、底部字幕框照舊。

### 5. 出片與上線
1. 重新合成語音（語音檔沒有存進 git），排時間軸，逐段輸出截圖自查。
2. 給站長看關鍵截圖（每章一張），同意後出片。
3. 上傳成新的不公開影片。網站 `videos/index.html` 的條目改成新的影片 ID，並更新片長和章節秒數；`publish/` 的章節表、字幕檔、網站條目草稿一起更新。
4. 開 draft PR。舊的 YouTube 影片不刪，由站長決定。

- 文字內容完全不動，只換畫面；如果新解剖和某句旁白有衝突，先列出來問站長，不自己改旁白。
