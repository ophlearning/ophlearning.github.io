## 案例 A 的注意事項（旁白與畫面都照實說）
- 右眼 OD（站長 2026-11-09 確認），術者坐 superior：錄影畫面下方＝12 點、右＝temporal。
- 這一眼 **zonule 弱**：放 IOL 前**另放了 CTR**（14:49.5–16:28）、最後**縫合主切口**（19:40 起）。站長 2026-11-09 選「用案例 A，略過 CTR 與縫合」：兩段都不在任何片段裡（`check.js` 檢查），旁白說「本例另放了／縫了，routine 不需要，這段略過」。
- **I/A**：從頭到尾是同一支**彎頭 coaxial tip**、都從主切口（2 秒一格看過整段 3 分鐘）；沒有換手、沒有雙手 I/A、沒有經側切口吸。主切口下方的處理＝把彎頭轉向側邊（13:20–13:36）。吸口朝哪裡在錄影上看不清楚，吸口方向只用模型講。
- **吸皮質的順序**：錄影看得到 tip 在哪一區（主切口這一側與中央 → 6 點那一側整片皮質剝向中央 → 3 點那一側 → 彎頭轉向主切口這一側），右邊模型照這個時間把區塊吸掉；每一區的範圍是示意，11:26–12:15 的中央那段（看不清楚吸哪裡）沒有放進影片。
- **IOL 打進去之後約 1 分半的調整**（側切口的扁平器械、主切口的細鑷子，16:54–18:28）細節看不清楚，略過；旁白照說。之後側切口的 cannula 碰 optic、瞳孔縮小（打了什麼看不出來）也略過，5-2 只說「這時瞳孔已經縮小」。
- **收尾**：I/A 一退出就用棉棒壓在主切口那一側的角膜上（19:31.5–19:39.5），樣子和 Liu 2023 的 swab pressing 相同，但旁白只描述動作、不說術者的用意；沒有看到 stromal hydration。
- **後囊皺褶**：吸皮質時沒有看到；調整 IOL 時（器械壓 IOL）看得到放射狀皺褶，那段略過，旁白沒講。
- 錄影去識別：抽格時只裁出眼睛範圍，畫面、參考圖都沒有燒進去的文字；聲音一律不用。

## 畫面上標「示意」的地方
| 段 | 內容 | 為什麼是示意 |
|---|---|---|
| 1-1、2-1、2-3 | 皮質的分布與厚度（片 0.2 mm、主切口下方多 0.45 mm） | 模型卡（`globe/CARD.md` 白內障 ③）：「主切口下方最難」是 Colvard 1997、Miyoshi 2022 的前提，沒有厚度數字 |
| 1-2、3-2 | 吸口朝上、皮質條被拉向中央、tip 的位置 | 常用做法；查不到比較研究（Hagan 1987 只說要知道吸口朝哪裡） |
| 1-3、1-4、2-3 | 右邊的區塊依錄影時間被吸掉、tip 的位置 | 錄影看得到 tip 在哪一區，看不到每一區的範圍與深度；模型的直 tip 只到得了 4–7 點的邊緣下 |
| 2-1 | 直的 tip 伸到主切口下方會撞到虹膜 | 模型推得（隧道往中央上升 18°；`check.js` 與 `globe/check.js` 13.6 檢查），沒有出處 |
| 2-2 | 雙手 I/A 的彎與尺寸、hydro-dispersion 沖離 0.3 mm | 做法依 Colvard 1997、Sakamoto 2002、Miyoshi 2022；器械尺寸與沖離的量示意 |
| 2-3 | 彎頭 tip | 模型沒有「彎頭 coaxial tip」，用雙手 I/A 的彎頭吸管畫在主切口（投影），標「彎頭 tip（示意）」 |
| 3-1、3-2 | 吸到後囊：帳篷約 1.4 mm、放射狀皺褶 | 查不到出處；動畫示意。第一步「腳退回 1 段、reflux」是常用做法，依腳踏的機轉（Quesada 2022） |
| 4-1 | 囊袋裡 OVD 撐開的量 | 示意（錄影看得到 OVD 的前緣，看不到深度） |
| 4-2、4-3 | injector 斜面朝下、IOL 出 nozzle 的姿勢、後 haptic 用 hook 壓進 | 示意；IOL 剛出口到打開之間（模型 `out` 0.3–0.8）模型會碰角膜，所以不畫、看錄影（`check.js` 檢查從來不畫這一段） |
| 4-2、4-4 | IOL optic 6.0、全長 13.0 mm；模型囊袋 9.6 mm | Osawa 2021 的一款 IOL，院內型號為準；Vass 1999 的 in vivo 囊袋 10.37 mm 比模型大約 0.7 mm（模型卡已註明） |
| 4-5 | 偏 0.8 mm、haptic 在 sulcus 的形狀 | 動畫示意；第一步「hook 撥轉 IOL」是常用做法 |
| 5-1、5-2 | 先清 optic 後面、再清前面；囊袋貼回 IOL、前房變深 | 順序與量示意；要清後面依 Biro 2006、Auffarth 2004 |
| 5-3、5-4 | 內口張開 0.12 mm、hydration 變白的範圍、棉棒壓住後兩唇貼合 | 機轉依 McDonnell 2003、Mifflin 2012、Liu 2023；量示意 |

## 依院內常規（待確認）

- 收尾用 stromal hydration 或 swab pressing；收尾前確認前房深度與切口不漏（5-4 第 3 句標「院內常規」）。
- 主切口寬（模型 2.4 mm）、側切口位置（約 2 點）：沿用 ①、②。
